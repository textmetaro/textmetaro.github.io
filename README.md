# text me

문자를 보내면 답장으로 사진이 오는 모바일 웹앱. 보낸 말의 키워드에 맞는 사진이
도착하고, 50장을 모으는 **도감**이 있습니다. iPhone 문자 UI 기반, Pretendard 폰트.

## 실행 (로컬 미리보기)
```bash
cd "이 폴더"
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
정적 파일이라 아무 정적 호스팅(예: Vercel, Netlify, GitHub Pages, S3)에 그대로 올리면 됩니다.

## 폴더 구조
```
index.html          진입점 + 설정 스위치(window.CONFIG) + X 공유 메타태그
css/style.css       스타일 (스플래시·도감=다크 타로 / 채팅=클래식 iMessage)
js/manifest.js      ★ 사진 50장 데이터(id·키워드·그룹) — 여기만 편집하면 됨
js/mapping.js       메시지 → 사진 매핑 엔진
js/placeholder.js   실제 사진 오기 전 타로카드 플레이스홀더(canvas) 생성
js/sound.js         타이핑/발송/수신 효과음 합성 + 진동(햅틱)
js/confetti.js      50장(완성) 달성 컨페티
js/app.js           화면 전환·상태 저장·도감·뷰어·공유 등 전체 로직
images/             실제 사진을 여기에 001.jpg ~ 050.jpg 로 넣으세요
assets/og-image.png X 미리보기 이미지(1200×630)
```

## 상대방(타로짱😏) / 실제 사진 구성 — 현재 상태
- 문자 상대 이름은 **타로짱😏**, 프로필 사진은 `images/profile.jpeg` (`CONFIG.avatar`로 변경).
- 도감 100칸 ↔ 실제 사진 100장 매핑은 **`js/photos.js`** (id → 실제 파일 경로).
  - 사진 순서를 바꾸려면 `photos.js`에서 각 id의 경로만 바꾸면 됨(파일 복사 불필요).
  - 새 사진으로 교체: 파일을 `images/`에 넣고 `photos.js`의 해당 id 경로 수정.
  - `photos.js`를 다시 만들려면: `images/`의 사진(=profile 제외)을 정렬해 001..100에
    자동 배정하는 생성 스크립트를 돌리면 됩니다(원하면 요청하세요).
- 답장·도감·상세보기 모두 **텍스트 없이 사진만** 표시(키워드/번호/제목 라벨 제거).

## 사진을 실제로 넣는 법 (참고: 파일명이 001.jpg 형식일 때)
1. 사진 파일을 `images/` 안에 **`001.jpg` … `050.jpg`** 이름으로 저장.
   (id는 `js/manifest.js`의 각 항목 `id`와 일치. 확장자는 `index.html`의
   `CONFIG.imageExt`에서 바꿀 수 있음)
2. `index.html` 상단의 `window.CONFIG.useRealImages` 를 **`true`** 로 변경.
   - `false`인 동안은 네트워크 요청 없이 타로 플레이스홀더가 보입니다.
   - `true`면 실제 사진을 쓰고, 없는 번호는 자동으로 플레이스홀더로 대체됩니다.

## 매핑 원리 (중요)
배포된 정적 앱이라 서버/AI 추론 없이 **100% 클라이언트에서 결정론적으로** 동작합니다.
`js/manifest.js`의 키워드·그룹 표가 "의미 이해"를 대신합니다.

우선순위:
0. **길이 보상(최우선)** — 글자수가 기준 이상이면 *내용과 무관하게* 지정된 사진이
   나옵니다(장문 이스터에그). `index.html`의 `CONFIG.lengthRules`에서 설정:
   ```js
   lengthRules: [
     { min: 100, id: "048" },   // 100자 이상
     { min: 200, id: "049" },   // 200자 이상
     { min: 500, id: "050" }    // 500자 이상
   ]
   ```
   가장 큰 `min`이 우선(예: 250자 → 200자 규칙). 입력 최대 길이는 `index.html`의
   textarea `maxlength`(현재 1000). 길이로 얻은 사진의 도감 라벨은 "N자 이상 ✍️".
1. **키워드 소유** — 각 키워드는 사진 1장을 소유. 메시지에 그 키워드가 들어있으면
   해당 사진이 옵니다. → **같은 키워드는 항상 같은 사진(랜덤 아님).**
   - 여러 키워드가 걸리면 *더 긴(구체적인)* 키워드가 우선, 길이가 같으면
     *문장에서 먼저 나온* 키워드가 우선. (예: "고양이 보고싶다" → 고양이)
2. **그룹 클러스터** — 비슷한 말(사랑/좋아/보고싶)은 같은 `group`으로 묶여
   비슷한 계열의 사진이 나옵니다. → **비슷한 단어 → 비슷한 사진.**
3. **결정론적 폴백** — 어떤 키워드도 안 걸리는 새로운 문장은 문장 해시로
   50장 중 하나에 고정 배정. → **무한한 입력도 커버, 같은 문장은 항상 같은 사진.**

### 특별 답장 (키워드 → 여러 메시지 이스터에그)
문자에 특정 단어가 포함되면 사진 대신 **여러 메시지가 순서대로** 답장으로 옵니다
(도감엔 영향 없음, 최우선 순위). `index.html`의 `CONFIG.specialReplies`에서 설정:
```js
specialReplies: [{
  match: ["text me", "텍스트미"],   // 대소문자·공백 무시하고 "포함"되면 발동
  messages: [
    { type: "text", text: "가사가 좋아서 ..." },
    { type: "text", text: "브리즈 상상하면서 했어 ㅋㅋ" },
    { type: "youtube", videoId: "7oea97f6uHs" }   // 탭하면 소리와 함께 재생
  ]
}]
```
- `type:"text"`는 상대 문자 말풍선, `type:"youtube"`는 유튜브 영상(썸네일→탭 재생).
- 규칙을 배열에 더 추가하면 다른 트리거도 만들 수 있어요.
- **화질**: 유튜브는 URL로 1080p 강제가 불가하고 *플레이어 크기*로 화질을 자동
  결정합니다. 그래서 탭하면 채팅 폭 꽉 차게 커지고(HD 유도) IFrame API로 1080p를
  요청합니다. 확실한 1080p는 플레이어의 **전체화면** 버튼으로. 컨트롤(화질 톱니바퀴/
  전체화면)은 기본 노출됩니다.

### 키워드/사진 편집하기
`js/manifest.js`의 각 항목만 고치면 됩니다:
```js
{
  "id": "001",              // images/001.jpg 와 연결
  "title": "The Lovers",    // 크게 볼 때 제목
  "emoji": "❤️",            // 플레이스홀더 심볼
  "hue": 345,               // 플레이스홀더 색
  "group": "love",          // 비슷한 사진 묶는 그룹(유사어 매핑용)
  "special": true,          // 특별 관리 이미지 표시(선택)
  "keywords": ["사랑","좋아","보고싶","설레","두근"]  // 이 사진을 부르는 말들
}
```
- 첫 키워드가 가장 강함. 한/영/축약형 여러 개 넣을수록 잘 잡힙니다.
- 특정 키워드가 특정 사진을 확실히 부르게 하려면, 그 키워드를 **그 사진에만**
  넣으세요(다른 사진과 겹치지 않게). 겹치면 위의 우선순위 규칙으로 결정됩니다.

### "특별 관리" 이미지 (질문 주신 부분)
별도 폴더를 만들 필요는 없습니다. 더 효율적인 방법:
- 재미 키워드로 확정 매핑하고 싶은 사진은 `manifest.js`에서 `"special": true`로
  표시하고, 그 사진의 `keywords`에 **독점 키워드**(다른 사진에 안 쓰는 말)를 넣기.
- 그러면 이스터에그처럼 "그 말 → 그 사진"이 100% 보장됩니다.
- 폴더로 나누고 싶다면 `images/special/` 같은 하위 폴더도 가능하지만, 파일 경로만
  달라질 뿐 로직상 이점은 없어서 **플래그 방식**을 추천합니다.

## 효과음 / 햅틱
- **실제 음원 넣기**: `sounds/`에 `type` / `send` / `receive` 파일(mp3·m4a·wav·ogg)을
  넣고 `index.html`의 `CONFIG.useCustomSounds = true`로 바꾸면 그 소리가 납니다.
  - `type`은 30~60ms로 아주 짧게 잘라야 빠른 타이핑에서 자연스럽습니다.
  - 파일이 없으면 **아이폰 느낌으로 합성한 소리**가 자동 대체됩니다(에셋 0으로도 동작).
  - ⚠️ 애플 순정 효과음을 그대로 넣어 공개 배포하면 저작권 문제가 될 수 있으니
    직접 녹음/라이선스 확보 음원을 권장합니다.
- **답장 연출**: 발송 → 잠깐 뒤 **"상대 입력중" 인디케이터(아이폰 … 점 3개)** → 사진 전달.
  타이밍은 `js/app.js`의 `preDelay`/`typeDelay`에서 조절.
- **햅틱(진동)**: **Android/Chrome**에서 동작. **iOS Safari는 웹 진동 API를 막아둬서**
  아이폰에선 진동이 생략되고 소리만 납니다(정상). iOS는 첫 탭 이후 소리가 켜집니다.

## 도감 알림 / NEW 표시
- 처음 발견한 사진은 채팅 답장 위에 **NEW! 뱃지**가 붙습니다(중복 수신은 안 붙음).
- 우측 상단 도감 아이콘의 빨간 배지는 **아직 도감에서 안 본 새 사진 수**만 표시하고,
  도감을 한 번 열면 사라집니다(알림 방식).

## 저장 / 공유
- 보낸 문자·도감은 **같은 브라우저 localStorage**에 계속 저장됩니다(키: `textme.v1`).
- 사진 상세에서 **공유**(가능하면 이미지 파일째 시스템 공유), **X 공유**(트윗 작성창),
  **저장**(그 사진만 PNG 다운로드). X 트윗창은 이미지 자동첨부가 안 되므로
  이미지 공유는 시스템 공유(공유 버튼)를 주로 쓰게 됩니다.

## X 미리보기 이미지
